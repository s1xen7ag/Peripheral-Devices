## <br>2. **Форм-фактори корпусів настільних комп'ютерів** <br>
- Горизонтальні корпуси (також відомі як настільні або Desktop-корпуси) призначені для розміщення комп'ютера у горизонтальному положенні, часто під монітором, що допомагає економити простір на столі.

- Повнорозмірна вежа (full tower) — це найбільший типорозмір комп'ютерного корпусу, який забезпечує максимальний простір для високопродуктивних компонентів, розширених систем охолодження та великої кількості накопичувачів. Вони ідеально підходять для ентузіастів, геймерів та професіоналів, які потребують максимальної гнучкості збірки та можливостей для майбутніх оновлень.

## <br>3. **Блок живлення - основні характеристики, конектори блоку живлення.**
В електричну розетку подається змінний струм (alternating current, AC). Однак всі компоненти
всередині комп'ютера вимагають постійного струму (direct current, DC). Для отримання постійного
струму комп'ютери використовують блок живлення, як показано на рисунку, що перетворює
змінний струм в постійний нижчої напруги.
<br><img width="480" height="540" alt="image" src="https://github.com/user-attachments/assets/dcca024a-25b6-4a79-a38a-24ed12eaf2a2" />
 <br><h1>Основні характеристики</h1>
- **Потужність (Вт/W):** Найважливіший параметр. Для офісних ПК достатньо 300–450 Вт, для ігрових — 500–750 Вт, для потужних систем з топовими відеокартами — 800-1000+ Вт.<br>
- **Сертифікат 80 Plus (ККД):** Визначає ефективність (Energy Efficiency). Класи: Standard, Bronze, Silver, Gold, Platinum, Titanium. Вищий клас означає менше нагрівання та нижче споживання електроенергії.<br>
- **Форм-фактор:** Розмір блоку. Найпоширеніший — ATX, також є SFX (для компактних корпусів).<br>
- **Лінії живлення:** Найважливіша лінія +12В (живить CPU та GPU). Якісні БЖ мають потужну лінію +12В, що майже дорівнює загальній потужності.<br>
- **Охолодження:** Зазвичай активне (вентилятор 120-140 мм). Також важлива наявність захисту (OPP, OVP, SCP) від перевантаження та короткого замикання. <br>

## <br>4. **Основні компоненти материнської плати (7 шт.)**
<br><img width="630" height="249" alt="image" src="https://github.com/user-attachments/assets/bd405ac2-45e4-4e00-8f19-006b94731375" />

**1. Сокет процесора (CPU Socket):** Місце, куди встановлюється центральний процесор (CPU). Існують різні типи сокетів (наприклад, LGA, AM), які сумісні з певними поколіннями процесорів.<br>
**2. Слоти пам'яті (RAM Slots / DIMM Slots):** Сюди встановлюється оперативна пам'ять (RAM), яка використовується для тимчасового зберігання даних, що активно використовуються.<br>
**3. Слоти розширення (Expansion Slots / PCIe Slots):** Використовуються для підключення додаткових карт розширення, таких як відеокарти (GPU), звукові карти, мережеві карти тощо. Найпоширеніші - PCIe (Peripheral Component Interconnect Express).<br>
**4. Чіпсет (Chipset):** Набір мікросхем, що контролює взаємодію між процесором, пам'яттю, слотами розширення та периферійними пристроями. Розділяється на північний (Northbridge) та південний (Southbridge) мости (хоча в сучасних архітектурах їх функції часто інтегровані).<br>
**5. Роз'єми SATA (SATA Ports):** Порти для підключення накопичувачів даних, таких як жорсткі диски (HDD) та твердотільні накопичувачі (SSD).<br>
**6. Порти USB (USB Ports):** Порти для підключення зовнішніх периферійних пристроїв, таких як клавіатури, миші, принтери, флеш-накопичувачі тощо.<br>
**7. Коннектори живлення (Power Connectors):** Місця для підключення кабелів живлення від блоку живлення до материнської плати, зокрема основного 20+4 pin ATX та 4+4 pin EPS для процесора.<br>
