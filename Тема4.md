## <br> **1) Огляд та характеристики слотів розширення (expantion slots) на материнській платі:**
**Слоти розширення (expansion slots) на материнській платі**<br>
— це фізичні роз’єми (зазвичай стандарту
PCIe), призначені для встановлення додаткових плат, що розширюють функціональність ПК: відеокарт, звукових та мережевих адаптерів. Основні характеристики включають тип (PCIe x16, x8, x4, x1), покоління (3.0, 4.0, 5.0) та кількість ліній, що визначають швидкість передачі даних.<br>
## Типи слотів:
**1) PCI Express (PCIe) x16:** Найдовші слоти, які використовуються переважно для встановлення відеокарт (GPU). Часто мають металеве посилення для надійного кріплення важких карт.<br>
**2) PCI Express (PCIe) x1/x4/x8:** Менші слоти для встановлення додаткових контролерів, мережевих адаптерів (Wi-Fi, Ethernet), звукових карт тощо.<br>
**3) M.2 Slot:** Спеціальний слот для високошвидкісних SSD-накопичувачів, що підтримують інтерфейс NVMe.<br>
**4) Старі стандарти (PCI):** У сучасних материнських платах зустрічаються вкрай рідко, призначені для застарілого обладнання.<br>

## Характеристики:
**1) Тип роз'єму:** Визначає фізичну сумісність (наприклад, PCIe x16 не влізе у слот x1).<br>
**2) Кількість ліній (x1, x4, x8, x16):** Чим більше ліній, тим вища пропускна здатність.<br>
**3) Покоління PCIe (3.0, 4.0, 5.0):** Кожне нове покоління подвоює швидкість передачі даних порівняно з попереднім.<br>
**4) Форм-фактор материнської плати:** Визначає максимальну кількість доступних слотів (наприклад, ATX має більше слотів, ніж Micro-ATX).<br>

```python
Слоти розширення забезпечують гнучкість у конфігурації комп'ютера, дозволяючи модернізувати його без необхідності 
заміни всієї материнської плати.
```
## <br> **2) Карти розширення (expantion cards) на інтерфейсі PCI-e (8 шт. для різних типів слотів):**
Інтерфейс PCI Express (PCIe) використовує різні фізичні розміри слотів (x1, x4, x8, x16) для розміщення різноманітних
карт розширення, які додають нові функції до комп'ютера.
## 1. Відеокарти (GPU) — PCIe x16:
Це найпоширеніший тип карт. Вони потребують максимальної пропускної здатності, тому використовують повнорозмірний слот x16. Сучасні стандарти (PCIe 4.0 та 5.0) дозволяють передавати величезні масиви даних для рендерингу графіки та обчислень ШІ.
<img width="480" height="324" alt="image" src="https://github.com/user-attachments/assets/64c5fc2a-ad46-4e36-bb81-21baba74d886" /><br>
## 2. Швидкісні NVMe накопичувачі — PCIe x4:
Хоча більшість SSD встановлюються в роз'єм M.2, існують карти розширення (AIC — Add-In Card), які вставляються безпосередньо в слот PCIe. Зазвичай вони використовують 4 лінії, що забезпечує швидкість у кілька гігабайт на секунду.
<img width="480" height="324" alt="image" src="https://github.com/user-attachments/assets/8c7c32c3-51ca-49d7-9d7c-7ccc4ed66356" /><br>
## 3. Мережеві карти 10GbE / 40GbE — PCIe x8 або x4:
Стандартні гігабітні карти працюють на x1, але професійне серверне обладнання для передачі даних на швидкості 10, 25 або 100 Гбіт/с потребує x4 або x8 ліній для уникнення «вузького місця» в шині.<br>
<img width="480" height="324" alt="image" src="https://github.com/user-attachments/assets/a2304759-d5f2-4ce8-a0bb-b75d777cc18d" /><br>
## 4. Звукові карти — PCIe x1:
Аудіофілські рішення або карти для запису звуку не потребують великої пропускної здатності. Для них ідеально підходить найменший слот x1. Це дозволяє розвантажити процесор від обробки звукових ефектів.<br>
<img width="350" height="350" alt="image" src="https://github.com/user-attachments/assets/75824c32-b7e0-4599-bfc3-6bf2c6c81802" /><br>
## 5. Контролери USB / Thunderbolt — PCIe x4:
Якщо на материнській платі не вистачає сучасних портів, можна встановити карту розширення. Для підтримки кількох портів USB 3.2 або одного Thunderbolt 4 зазвичай потрібен слот x4.<br>
<img width="400" height="400" alt="image" src="https://github.com/user-attachments/assets/82f34473-dbe6-4d19-b506-2dff723694a7" /><br>
## 6. Карти захоплення відео (Capture Cards) — PCIe x4 або x1:
Використовуються стрімерами та відеографами для запису сигналу з консолей або камер. Моделі, що підтримують 4K при 60 FPS, зазвичай вимагають x4, тоді як простіші 1080p моделі задовольняються x1.<br>
<img width="400" height="268" alt="image" src="https://github.com/user-attachments/assets/5bc09257-9e0f-4e4f-bfed-53d01110c2ef" /><br>
## 7. RAID-контролери — PCIe x8:
Це професійні плати для створення масивів з багатьох жорстких дисків або SSD. Оскільки вони обробляють потоки даних від багатьох накопичувачів одночасно, їм необхідна висока пропускна здатність слота x8.<br>
<img width="323" height="300" alt="image" src="https://github.com/user-attachments/assets/e7d32263-10a5-4e4b-b855-8fcb7c188156" /><br>
## 8. Адаптери Wi-Fi та Bluetooth — PCIe x1:
Найкомпактніші карти. Оскільки навіть найшвидший Wi-Fi 6/7 не вичерпує ліміт однієї лінії PCIe 3.0+, роз'єм x1 є стандартом для таких модулів.<br>

## Факт
```python
Ви можете вставити карту «меншого» типу в «більший» слот (наприклад, карту x1 у слот x16), і вона буде працювати. 
Але навпаки — вставити фізично велику карту в малий слот — не вийде (хіба що слот має відкритий задній край).
```
