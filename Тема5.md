## <br> 1) Типи та характеристики SSD-накопичувачів: 
SSD-накопичувачі (твердотільні диски) забезпечують високу швидкість роботи ПК, маючи основні характеристики: обсяг (256 ГБ–4+ ТБ), швидкість читання/запису (500–10 000+ МБ/с), ресурс (TBW) та форм-фактор.Головні типи — це SATA (2.5") для старих ПК та NVMe M.2 (PCIe 3.0/4.0/5.0) для сучасних систем, які відрізняються продуктивністю та типом пам'яті (TLC/QLC)
## Типи:
**1) SATA 2.5" SSD:** Класичний форм-фактор, підключається через кабель SATA. Обмежений швидкістю до 550–600 МБ/с. Найкращий варіант для модернізації старих ноутбуків та ПК.<br>
<img width="320" height="400" alt="image" src="https://github.com/user-attachments/assets/3f30d856-44b5-4a95-87c9-0b3e5142eb52" /><br>

**2) M.2 SATA SSD:** Компактна планка, але використовує повільний протокол SATA (швидкість до 550 МБ/с).<br>
<img width="320" height="400" alt="image" src="https://github.com/user-attachments/assets/61251a2f-fc14-4a73-ac9c-decb5b77afca" /><br>

**3) M.2 NVMe (PCIe) SSD:** Найшвидший сучасний стандарт. Підключається безпосередньо до материнської плати <br>
<img width="320" height="400" alt="image" src="https://github.com/user-attachments/assets/0825d97a-4926-461d-b7cc-f1166a56bbd0" /><br>
- PCIe 3.0: Швидкість $\sim$3000-3500 МБ/с.
- PCIe 4.0: Швидкість 5000–7500 МБ/с (ідеально для геймінгу та професійної роботи).
- PCIe 5.0: Найновіший стандарт, швидкість 10 000+ МБ/с.
- mSATA SSD: Застарілий стандарт для ноутбуків, схожий на M.2.
## <br> Типи флеш-пам'яті (NAND):
```python
Ви можете вставити карту «меншого» типу в «більший» слот (наприклад, карту x1 у слот x16), і вона буде працювати. 
Але навпаки — вставити фізично велику карту в малий слот — не вийде (хіба що слот має відкритий задній край).
```
**1) SLC (Single-Level Cell):** 1 біт у комірці. Найшвидша і найнадійніша, але дорога. Використовується у промислових пристроях.<br>
**2) MLC (Multi-Level Cell):** 2 біти. Хороший баланс швидкості та ресурсу.<br>
**3) TLC (Triple-Level Cell):** 3 біти. Найпопулярніший тип, оптимальний для користувачів.<br>
**4) QLC (Quad-Level Cell):** 4 біти. Найвища щільність і низька ціна, але найменший ресурс роботи (TBW).<br>
**5) 3D NAND:** Технологія розміщення шарів пам'яті один над одним, що підвищує надійність і обсяг (може бути 3D TLC, 3D QLC).<br>

## Інформація про накопивувач, Температура, Швидкість читання:
```python
$disk = Get-PhysicalDisk
$reliability = Get-PhysicalDisk | Get-StorageReliabilityCounter
Write-Host "ІНФОРМАЦІЯ ПРО НАКОПИЧУВАЧ" -ForegroundColor Cyan
foreach ($d in $disk) {
    $rel = $reliability | Where-Object DeviceId -eq $d.DeviceId
    Write-Host ""
    Write-Host "Модель: " $d.FriendlyName -ForegroundColor Yellow
    Write-Host "Тип носія: " $d.MediaType
    Write-Host "Шина: " $d.BusType
    Write-Host "Розмір (GB): " ([math]::Round($d.Size/1GB,2))
    Write-Host "Стан здоров'я: " $d.HealthStatus
    if ($rel.Temperature) {
        Write-Host "Температура (°C): " $rel.Temperature -ForegroundColor Green
    }
    else {
        Write-Host "Температура: недоступна"
    }
}
Write-Host ""
Write-Host "ШВИДКІТЬ ЧИТАННЯ за 3 секунди" -ForegroundColor Cyan
$testFile = "$env:TEMP\speedtest.tmp"
$sizeMB = 1024  # 1GB файл
fsutil file createnew $testFile ($sizeMB * 1MB) | Out-Null
$start = Get-Date
$stream = [System.IO.File]::OpenRead($testFile)
$buffer = New-Object byte[] (4MB)
$bytesRead = 0
while ((Get-Date) - $start -lt [TimeSpan]::FromSeconds(3)) {
    $read = $stream.Read($buffer, 0, $buffer.Length)
    if ($read -eq 0) { break }
    $bytesRead += $read
}
$stream.Close()
$speedMB = [math]::Round(($bytesRead / 1MB) / 3, 2)
Write-Host "Швидкість читання ≈ $speedMB MB/s" -ForegroundColor Green
Remove-Item $testFile -Force
```
